# 发布检查清单

## 自动门禁

- [ ] `pnpm install --frozen-lockfile`
- [ ] `pnpm check`
- [ ] `pnpm release:preflight`
- [ ] 仓库中不存在未授权模型或来源不明品牌素材
- [ ] updater 仍为 disabled，除非 endpoint、公钥和发布签名条件全部完成
- [ ] Draft Release 明确标记 Windows/Linux 未签名及 macOS ad-hoc 签名状态

## 宠物与许可

- [ ] Momo 的 `LICENSE.txt` 与 `ASSET-SOURCES.md` 完整并匹配实际资源
- [ ] 每个内建宠物都通过与外部包相同的目录校验
- [ ] 精灵表透明边缘、网格尺寸、帧序号和循环状态正确
- [ ] 待机、点击、一次性动作、切换动作和快捷键可正常恢复到预期状态
- [ ] 低帧率限制下动作节奏可接受，切换期间没有闪烁或残影

## Windows 真机

- [ ] 透明窗口、拖动、点击动作、穿透、置顶、任务栏与托盘
- [ ] 开机自启动和全局动作快捷键
- [ ] 100%/125%/150% DPI、多显示器与边界保持

## macOS 真机

- [ ] 透明窗口、NSPanel 行为、拖动、点击动作、穿透、置顶与托盘
- [ ] 开机自启动和全局动作快捷键权限引导
- [ ] Retina、多显示器、全屏空间与窗口恢复

## Linux X11 真机

- [ ] 透明窗口、拖动、点击动作、穿透、置顶、任务栏与托盘
- [ ] 开机自启动与全局动作快捷键
- [ ] 多显示器和缩放

Wayland 不属于首版验收范围。自动 CI 构建不能替代上述真机检查。
