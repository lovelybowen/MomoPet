# MomoPet Temporary Icon

`momopet-app-icon.png` was generated specifically for the MomoPet scaffold with OpenAI image generation on 2026-08-08. It is not inherited from the upstream project and is intended to be replaced by the final brand artwork.

Derived desktop icons live in `src-tauri/icons/`. The 32px derivative is also used for the tray, and the 128px derivative is used by the no-model screen.

Generation prompt:

```text
Use case: logo-brand
Asset type: temporary cross-platform desktop application icon for MomoPet
Primary request: create an original, compact pet-companion symbol that subtly combines a rounded lowercase m silhouette with two small pet ears and a calm friendly face; no specific animal species
Scene/backdrop: full square icon with an opaque warm off-white background, generous safe padding, no transparency
Style/medium: crisp flat geometric brand mark, vector-friendly shapes rendered as a polished raster icon, refined and playful rather than childish
Composition/framing: centered single symbol, readable at 16 px, strong silhouette, balanced negative space
Color palette: coral red primary, deep teal secondary, charcoal details, warm off-white background
Constraints: no words, no letters drawn literally, no gradients, no shadows, no mockup, no border, no watermark, no existing brand resemblance
```
